Flutter Calculator App

The Flutter Calculator App is a simple and user-friendly calculator application developed using Flutter and Dart. This project provides basic mathematical operations such as addition, subtraction, multiplication, division, and percentage calculation. It also includes features like decimal number support, clear (AC), delete (DEL), and division-by-zero error handling. The application uses Flutter widgets and Material Design components to create a clean and responsive user interface. This project helps beginners understand Flutter project structure, Dart programming, widget layouts, StatefulWidget, setState(), button click handling, and basic calculation logic. The application can be run on Android devices and emulators using Android Studio or Visual Studio Code. This project is suitable for beginners who want to learn mobile application development using Flutter and Dart. Future improvements may include calculation history, scientific calculator functions, theme customization, and support for complex mathematical expressions.
